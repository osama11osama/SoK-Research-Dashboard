Multi-Source Paper Finder Tool

Search and add research papers from multiple academic databases simultaneously

The Multi-Source Paper Finder Tool is an intelligent academic search aggregator designed specifically for Systematization of Knowledge (SoK) research. Instead of manually searching multiple databases one by one, this tool simultaneously queries five major academic sources and intelligently merges their results into a unified, deduplicated list.

Supported Academic Databases:

  • • DBLP: Computer Science Bibliography - Best for conference papers (USENIX, NDSS, CCS, etc.)
  • • Semantic Scholar: AI-powered summaries, citation counts, and influential paper metrics
  • • OpenAlex: Open alternative to Google Scholar with comprehensive metadata
  • • arXiv: Preprints and cutting-edge research before formal publication
  • • Crossref: DOI validation and authoritative publication metadata

Time Efficiency

Search all five databases in parallel instead of visiting each one separately. What would take 10-15 minutes now takes seconds.

Comprehensive Coverage

No single database has everything. DBLP excels at conferences, arXiv has preprints, Semantic Scholar provides AI insights. This tool combines them all.

Automatic Deduplication

The same paper found in multiple sources is automatically merged, showing you all sources where it was discovered. No manual duplicate checking needed.

Methodology Documentation

Every search is automatically logged with query terms, sources used, and timestamp. This creates an audit trail for your SoK methodology section, proving systematic paper selection.

AI-Powered Insights

For Semantic Scholar papers, get instant TLDR summaries and abstract previews to quickly assess relevance without opening each paper.

1. Choose Your Search Sources

Select which databases to search based on your needs:

  • For conference papers: Enable DBLP and OpenAlex
  • For recent preprints: Enable arXiv
  • For comprehensive coverage: Enable all sources
  • For AI summaries: Ensure Semantic Scholar is enabled

2. Craft Effective Search Queries

Use specific, relevant keywords:

  • Combine multiple terms: "browser extension" AND security
  • Use domain-specific terms: manifest v3, web extension privacy
  • Try variations: Chrome extension, Firefox add-on
  • Include venue names: USENIX, NDSS (works best with DBLP)

3. Review and Filter Results

After searching, you'll see:

  • Source badges: Shows which databases found each paper
  • Citation counts: Helps identify influential papers
  • Abstract previews: Quick relevance assessment
  • AI summaries: Click "Get AI Summary" for Semantic Scholar papers

4. Add Papers to Your Collection

When you find relevant papers:

  • Click "Add Paper" to open the form
  • Review and edit metadata if needed
  • Set reading status (To Read, In Progress, Read)
  • The system automatically logs the search query and sources used

💡 Pro Tip:

Use the predefined quick searches for common topics, then refine your query based on initial results. Papers found in multiple sources are often more influential and should be prioritized.
