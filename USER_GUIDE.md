# SoK Research Dashboard - User Guide

Quick guide to using the SoK Research Dashboard for collaborative research management.

## Getting Started

### Registration & Access

1. **Register**: Go to `/register` and create an account
2. **Wait for Approval**: Your account must be approved by the Super Admin before you can log in
3. **Login**: Once approved, log in at `/login`

---

## Main Features

### 📚 Viewing Papers

- **Papers Page**: See all research papers in the collection
- **Filter Options**: Filter by reading status, tags, threat models, venue, or year
- **Search**: Use the search bar to find papers by title, authors, venue, or key findings
- **Paper Details**: Click on any paper to view full details, metadata, and notes

### ➕ Adding Papers

1. Click **"Add Paper"** button on the Papers page
2. Fill in the required information:
   - Title, Authors, Venue, Year, Link
   - Reading Status (To Read, In Progress, Read)
   - Tags and SoK metadata (category, method, threat model, etc.)
3. Click **"Create Paper"**

**Tip**: Use the **Paper Finder Tool** (from navigation) to search and import papers from academic databases (DBLP, Semantic Scholar, OpenAlex, arXiv, Crossref).

### 📝 Adding Notes

Notes help track progress and insights about papers:

1. Open a paper's detail page
2. Scroll to **"Add Note"** section
3. Choose visibility:
   - **Public**: Visible to all users (for sharing insights and progress)
   - **Private**: Only visible to you (for personal thoughts)
4. **Use Templates** (optional): Click "Templates" button for structured note formats:
   - Summary Template
   - Key Findings Template
   - Critique Template
5. Write your note and click **"Add Note"**

### 👁️ Viewing Progress & Notes

- **Public Notes**: See all public notes on paper detail pages (visible to everyone)
- **Reading Status**: Papers are marked as "To Read", "In Progress", or "Read" - this shows what you're currently working on
- **Dashboard**: View statistics about papers, notes, and progress

### 🗑️ Managing Papers

- **Delete Papers**: Super Admin can delete papers that are not important
- **Edit Papers**: Super Admin can edit paper details and metadata
- **Favorites**: Mark papers as favorites to prioritize them

### 🔍 Paper Finder Tool

Use the **Paper Finder Tool** (from navigation menu) to:
- Search across multiple academic databases
- View AI-generated summaries (TLDR) for Semantic Scholar papers
- Import papers directly into the dashboard

---

## User Roles

- **SUPER_ADMIN**: Full access - can add, edit, delete papers, approve users, manage settings
- **REVIEWER_NOTE**: Can view papers, add public and private notes
- **REVIEWER_VIEW**: Can view papers and add private notes only

---

## Quick Workflow

1. **Browse papers** to see what's in the collection
2. **Add new papers** using the "Add Paper" button or Paper Finder Tool
3. **Add notes** (public for sharing progress, private for personal thoughts)
4. **Update reading status** to show what you're currently working on
5. **Use filters and search** to find specific papers
6. **Delete papers** that are not relevant (Super Admin only)

---

## Tips

- Use **public notes** to share progress and insights with your team
- Use **reading status** to show what you're currently working on
- Use **tags** to categorize papers by topic
- Use **Paper Finder Tool** to quickly import papers from academic databases
- Use **note templates** for consistent note formatting
- **Export papers** to BibTeX, CSV, or JSON formats as needed
